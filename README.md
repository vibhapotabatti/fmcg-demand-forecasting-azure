# FMCG Demand Forecasting & Stockout Early Warning (Azure)

> **Portfolio project on simulated data.** Not employer or client work. The data is generated by `src/gen_demand_data.py` to mimic weekly FMCG hygiene and health sales, modelled on supply chain processes I supported in application support.

**Planner question:** which SKU at which distribution centre will run out in the next 2–4 weeks, and how much stock should move to prevent it?

## Results (simulated data, seed 42)
| Metric | Value |
|---|---|
| WAPE, LightGBM (26-week backtest, 2-week horizon) | **13.9%** |
| WAPE, seasonal-naive baseline | 19.2% |
| Forecast bias | +0.4% |
| Stockout weeks caught by the risk flag | 99% (52% of flags were real stockouts) |

## What the pipeline does
1. **Ingestion:** weekly sales/inventory, promo calendar and SKU master land in the raw zone (ADF in the cloud design; local CSVs here).
2. **Cleaning:** standardise DC codes, drop duplicate batch reruns, split returns out of sales, interpolate missing loads (flagged), and **unconstrain demand** in stockout weeks so the model does not learn the shortage.
3. **Features:** lags (2, 3, 4, 52 weeks), rolling mean, week of year, flu-season flag, promo type.
4. **Model:** global LightGBM across all SKU × DC series, compared with a same-week-last-year baseline on a 26-week holdout.
5. **Risk flag:** stock on hand covering less than 0.4 weeks of forecast demand.
6. **Delivery:** Power BI pages for the planner cockpit, forecast accuracy and promo uplift. DAX in [`dax_measures.md`](dax_measures.md).

## Run it locally
```bash
pip install -r requirements.txt
python src/gen_demand_data.py      # writes data/*.csv
python src/forecast_backtest.py    # prints metrics, writes dashboard_data_forecast.json
```
Open `dashboard/report-prototype.html` in a browser for a preview of the Power BI report layout.
